## 🌌 About The Project

**Marvel Omniverse Nexus** is an interactive Marvel knowledge archive inspired by S.H.I.E.L.D. technology and the Cerebro intelligence system.

The platform brings together the Marvel Cinematic Universe, legendary comic storylines, iconic superheroes, villains, and essential comic reading guides in one centralized experience.

Explore the Marvel universe, discover hidden connections between stories, investigate character dossiers, and interact with an AI-powered Marvel assistant.

**Welcome to the Omniverse Archives, Agent.**

## 🚀 Getting Started

Want to explore the project locally?

**1. Clone the repository**

```bash
git clone https://github.com/NOXWAL/Marvel-.git
```

**2. Navigate to the project folder**

```bash
cd Marvel-
```

**3. Launch the website**

Open `index.html` in your browser.

**4. Explore the Multiverse!**

Start exploring Marvel movies, comic storylines, characters, and much more.

## 🧠 AI Configuration

Marvel Omniverse Nexus includes an extensive built-in offline knowledge archive.

For additional AI-powered functionality, users can optionally configure a Google Gemini API key through the Cerebro AI Settings panel.

**Privacy Note:** The configured key is stored in the browser's LocalStorage. Keep your API key private and avoid using it on shared devices.
